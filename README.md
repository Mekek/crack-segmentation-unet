# Сегментация трещин с U-Net

Пет-проект по семантической сегментации трещин на изображениях дорожного покрытия. Модель U-Net сравнивается с классическими методами OpenCV: адаптивной бинаризацией, Canny, морфологией, шумоподавлением и фильтрацией в частотной области.

## Результаты

Все параметры классических методов выбирались на validation-части. Test-выборка использовалась только для итоговой оценки.

| Метод | Test Dice | Test IoU |
|---|---:|---:|
| U-Net | **0.7987** | **0.6873** |
| Denoise + adaptive threshold + Canny | 0.6065 | 0.4769 |
| Fourier low-pass + adaptive threshold + Canny | 0.5785 | 0.4459 |

В ноутбуке есть полный цикл: чтение и проверка пар изображение--маска, разбиение train/validation, аугментации, обучение, графики метрик, подбор параметров базовых методов и визуальное сравнение ошибок.

## Подготовка данных

Скачайте датасет DeepCrack и положите файлы в такую структуру:

```text
data/DeepCrack/
├── train_img/
├── train_lab/
├── test_img/
└── test_lab/
```

Имена изображения и маски должны совпадать без расширения. Если имена не совпадают, ноутбук попарно сопоставит отсортированные списки файлов.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Откройте `deepcrack_unet_segmentation.ipynb` и выполните ячейки по порядку. CUDA ускорит обучение, но ноутбук также работает на CPU.

## Воспроизводимость

Используется фиксированный `SEED = 42`. Ноутбук сохраняет лучшую модель по Dice на validation-части в `artifacts/unet_deepcrack.pt`.
